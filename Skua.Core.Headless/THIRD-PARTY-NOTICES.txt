Skua.Core.Headless / Skua.Core.Headless.Tests - third-party notices
=====================================================================

Parts of the AQW protocol handling in this library and its test fake server were
ported from, or closely follow, the two MIT-licensed projects below. They were
used as read-only references; no code from them is executed or redistributed as is.

Where their logic was ported:
  * Seraph (app/lib/net/protocol.js, app/lib/net/headless.js, app/lib/skua/swfworld.js,
    app/lib/updater.js, app/tests/fakeaqw.js):
      - login/handshake sequence and packet shapes, outbound pacing numbers (220 ms,
        500 ms for 30 s after "slow down", 60-packet cap, aggroMon merging), AFK
        clearing, liveness probing rule, world model packet handlers (moveToArea,
        uotls/mtls, ct/cb, aura events, addItems/dropItem/getDrop/turnIn, quests,
        bank), client version discovery from the game SWF (vParam scan);
      - the test fake server (Skua.Core.Headless.Tests/Fakes/FakeAqwServer.cs) is a
        C# port of fakeaqw.js.
  * aqx (crates/aqx-protocol, crates/aqx-client, skua/Host):
      - NUL framing and Z-packet decoding including the raw-deflate fallback, packet
        builders (gar, tryQuestComplete, SmartFox parameter rules), the client
        version retry on "requires AQW game version X", the post-join load order
        (moveToCell + retrieveUserData, then retrieveInventory), and the pext event
        shape used for Skua.

Phase 3 (client rules, maps; Skua.Core.Headless/Rules, Client, Maps) ported from Seraph app/lib/skua/swfworld.js
and app/lib/skua/mapcells.js, which follow the decompiled AQW client (World.as, Game.as, Avatar.as):
  * rank table and rank math (RANK_POINTS, rankFromPoints, updateRep, initFaction);
  * quest slot values in strQuests*, achievements, maximumQuestTurnIns, checkAllQuestStatus, questAcceptable;
  * InvCat inventory pools (isMisc/isHouse/poolOf/isFullFor/freedBy) and hasSpaceFor;
  * World.lock cooldown table, maximumShopBuys, the sendBuyItemRequest checks;
  * the skill bar (onSAct, potion slot), actionTimeCheck, testAction target selection, getActionResult,
    showActionResult, the auto attack loop, actionRefused, setTarget/cancelTarget/approachTarget;
  * HUD aura stacks (hudAuraSync, hudAuraSeed, hudAuraSnap, hudAuraClear, auraSnapshots);
  * party packets (pa/pr/pl/pk) and following server moves (gtc, dungeonMTC, resTimed);
  * reading map cells from DefineSceneAndFrameLabelData / FrameLabel tags (the SWF reader itself, the pad
    detection through SymbolClass/PlaceObject and the cache are new code).
skua.swf's own semantics (Skills.as, Shop.as, Auras.as, Inventory.as, Monster.as) come from this repository's
Skua.AS3 sources.

The LZMA decoder for "ZWS" SWF files (Skua.Core.Headless/Maps/LzmaDecoder.cs) is an independent C#
implementation of the LZMA algorithm as specified by Igor Pavlov's LZMA SDK (LzmaSpec.cpp and lzma-specification.txt,
https://www.7-zip.org/sdk.html), which the author has placed in the public domain. No SDK code is included and no
package is referenced.

The lenient base64 decoding of Z packets is copied from this repository's own
Skua.Core/GameProxy/CaptureProxy.cs.
